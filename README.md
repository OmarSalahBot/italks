# 💬 iTalks — Real-Time Chat App (MERN Stack)

iTalks is a modern **real-time chat application** built using the **MERN stack (MongoDB, Express, React, Node.js)**.  
It allows users to chat instantly, share messages, and connect with friends in a sleek and responsive interface.

---

## 🚀 Features

- ⚡ Real-time messaging using **Socket.io**
- 👥 One-to-one 
- 🔐 Secure authentication (JWT)
- 📸 Profile pictures and user status
- 💾 Persistent chat storage (MongoDB)
- 🎨 Clean UI with **Tailwind CSS**
- 🔔 Real-time online/offline indicators

---

## 🧩 Tech Stack

| Category | Technology |
|-----------|-------------|
| Frontend | React, Vite, Tailwind CSS |
| Backend  | Node.js, Express.js |
| Database | MongoDB |
| Realtime | Socket.io |
| Auth     | JSON Web Token (JWT) |
